# Flask Todo Web App 📝

A simple and functional To-Do Web Application built using Flask, with features like task creation, updating, deletion, and search. It’s designed to help users manage daily tasks efficiently through a clean and responsive interface.

## 🚀 Features

* Add new tasks
* Edit existing tasks
* Delete completed or unwanted tasks
* Mark tasks as done or pending
* Search tasks instantly by name or keyword
* Fully responsive design

## 🛠️ Tech Stack

* **Backend:** Flask (Python)
* **Frontend:** HTML, CSS, Bootstrap
* **Database:** SQLite (via SQLAlchemy)

## Installation

1. Clone the repository
```bash
git clone https://github.com/AamirNeyazi2499/Flask-Todo-Web-App.git
```

2. Install dependencies
```bash
pip install -r requirements.txt
```

3. Run the application
```bash
python app.py
```

## 🧩 Usage

Enter a task in the input field and click Add.

Use Edit or Delete options to modify tasks.

Search bar filters your tasks instantly.

All data is saved locally in SQLite.
